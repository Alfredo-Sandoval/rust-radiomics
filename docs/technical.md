# Technical notes

## Precision

Shape, intensity histogram, IVH and texture features are float64 on the CPU. First-order
statistics and the local and global intensity peaks are computed from float64 intensities and
returned as float32 values, as in mlx-radiomics; the mean follows its float32 summation order.
First-order voxel maps are evaluated in float32, and the other voxel families compute in
float64 and deliver float32 samples. Retained float64 maps widen those float32 samples, and saved maps and
streamed batches are float32. Integer counts are exact. Sums over many terms use
compensated summation.

## How values are checked

Each feature family, filter and workflow is tested against three kinds of reference.

- **Exports from mlx-radiomics v1.1.0.** Fixtures and goldens are generated by the scripts in
  `validation/` and committed (see [Development](development.md)). The committed corpus holds 12
  image and mask pairs, 96 mlx-radiomics records and 26 PyRadiomics float64 records. Each
  record names the command and versions that produced it.
- **IBSI reference tables and maps.** The IBSI 1 digital phantom and CT phantom, and the
  IBSI 2 response maps and consensus values.
- **Independent float64 oracles.** Direct convolution and NumPy FFT constructions where
  mlx-radiomics cannot run, as for Simoncelli and Riesz.

A value passes when `abs(actual - reference) <= atol + rtol * abs(reference)`. NaNs match
each other, and infinities must match in sign.

| Comparison | `rtol` | `atol` |
| --- | ---: | ---: |
| mlx-radiomics, intensity and texture features | 2e-5 | 2e-6 |
| mlx-radiomics, shape, shape2D and intensity-dependent morphology | 3e-6 | 2e-6 |
| PyRadiomics float64 goldens (comparison tool default) | 1e-8 | 1e-10 |

These are measured constants. A failing comparison is a defect in the code or the
reference, and the tolerance is never widened to pass it. The IBSI tests use the published
tolerances.

## Validation

IBSI 1 and IBSI 2 data are named here as validation data. The IBSI CT phantom and the
LUNG1 images are CC BY-NC and are not distributed with this repository. The suites that
read them run when their paths are set (see [Development](development.md#checks)).

### IBSI 1

- **Digital phantom.** 482 of 482 rows with a published reference value pass. Integer-valued
  rows must match exactly. The 487 reference rows include five without a published value.
- **CT phantom, configurations A to E.** 1,322 of 1,322 rows pass the declared rules
  (346 each for configurations A and B, and 210 each for C, D and E). 1,321 meet the literal
  published tolerance. The remaining row passes the declared rule for zero-tolerance rows,
  which compares both values after rounding to three significant digits. A nonzero
  published tolerance is always applied literally.

### IBSI 2

- **Phase 1 response maps.** All 33 maps are within 1 % of the reference range, the IBSI 2
  criterion.
- **Phase 2 consensus values.** All 323 rows of the CT consensus grid pass at the published
  tolerance. The additional checks on the manual's DFT Fourier grid pass 69 of 71. The two
  exceptions are the Simoncelli quartile coefficient of dispersion in configuration 8.A and
  the minimum in 9.B. They are recorded as named exceptions in the test.

### Agreement with mlx-radiomics

- **Export comparison.** 88 mlx-radiomics reports agree with this port, covering 617,456
  values: 8,288 ROI values and 609,168 voxel values. Eight further records are inputs that
  mlx-radiomics rejects, and this port rejects them too.
- **Spatial processing.** Each of the three IBSI CT phantom interpolation cases
  (891,000 voxels) matches mlx-radiomics in its rounded intensities, selected labels and
  discretized bins. Physical-to-index matrices for 961 grids match SimpleITK bit for bit,
  and every label matches across 80 synthetic oblique and reflected grids (22,400 voxels).
- **Streaming and retained maps.** On eight array and file cases, both map dtypes and both
  delivery orders matched within tolerance for all 2,800 values. Coordinates and per-feature
  validity counts matched exactly. All 1,512 voxel scheduler fixtures reproduced the memory
  estimate or refusal of mlx-radiomics, and six streamed extractions reproduced its
  callback lengths.
- **Local intensity.** Two anisotropic fixtures match mlx-radiomics exactly.
- **First order.** 1,008 ROI and 87,024 voxel comparisons pass the tolerances above.

### Threading

Results do not depend on the number of Rayon threads in the cases tested. On LUNG1-001, all
181 ROI scalars have identical IEEE bit patterns with 1 and 18 threads, and all 5,081,427
selected values in the 93 default voxel maps match bit for bit at both counts. The test
suite compares every image type, the resampling paths, the 21 first-order voxel maps, the
texture families and the shape features bit for bit between a one-thread pool and the
default pool. The Fourier-based Moran's I and Geary's C reduce fixed slabs in order, so
they are deterministic as well. They differ from the exact pairwise sum by relative
6.2e-12 and 4.8e-13 on LUNG1-001.

### Known numerical differences

Two synthetic LBP3D cases select a different local peak from the Metal result of
mlx-radiomics; see [Limits](guide/limits.md#differences-from-mlx-radiomics).
